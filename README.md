# Startup Landing Page - Experiment 05

A responsive startup landing page demonstrating JavaScript DOM elements and events.

## Files
- `index.html` - Page structure
- `style.css` - Page styling
- `script.js` - DOM manipulation and event handling

## Features
- Navigation links
- Get Started button with a click event
- Contact form with required name and email fields
- Input event that reads the name as the user types
- Submit event that displays a thank-you message

## Technologies
HTML5, CSS3 and JavaScript.

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. No installation is required.

## JavaScript concepts
`getElementById()`, `querySelector()`, `addEventListener()`, click/input/submit events, `textContent`, and `event.preventDefault()`.

Note: The contact form is a front-end demonstration only. It does not send or store data on a server.
